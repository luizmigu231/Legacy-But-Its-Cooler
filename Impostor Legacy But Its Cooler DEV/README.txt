Impostor Legacy But Its Cooler - Settings

O sistema usa o mesmo metodo do sistema antigo: ele prepara o chart antes de jogar, substituindo o normal.json no caminho original da musica.

Skins:
- Normal: usa o player2 original do chart.
- Skin: procura automaticamente um personagem com o mesmo nome do player2 + "skin".
  Exemplo: pink -> pinkskin, black -> blackskin.
- Se a versao "skin" nao existir, o personagem original e mantido.

Backlit:
- On: usa o stage configurado em stage.On.
- Off: usa o stage configurado em stage.Off.

Para adicionar uma skin, basta criar o personagem com o mesmo nome base terminado em "skin".
